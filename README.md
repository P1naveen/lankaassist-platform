# LankaAssist Platform

LankaAssist Platform is a secure financial and natural disaster
assistance coordination platform for Sri Lanka.

## Main Users

- Beneficiaries
- Donors
- Volunteers
- Verifiers
- Administrators

## Main Features

- Individual assistance requests
- Group assistance requests
- Natural disaster assistance
- Economic hardship assistance
- Financial and physical donations
- Volunteer coordination
- Anonymous donor support
- Secure role-based access

## Main Technologies

- Git and GitHub
- Spring Boot
- MySQL
- Docker
- Jenkins
- Postman
- React
